# Use the completed Algebra 1/2 bank

Open `downloads/Test-and-Practice-Studio-v0.25.0-rc.4.html` in a current desktop browser. Choose Algebra 1/2 and enable the engine-only filter. Search for a lesson, `M3 Lesson`, or `M3 Topic` to find the new authored tasks. There are 378 working entries across Lessons 1–123 and Topics A–J.

Preview and select tasks, set the variant and workspace, and create a student packet and separate teacher key with Word or Print/PDF. Save the teacher session to reuse selections and seeds with this version. Earlier downloads remain available for earlier sessions.

Standards codes are not required. Construction, graphing, explanation and method-production tasks are marked for teacher review; reference answers and criteria appear in the key. Supply graph paper and construction tools when requested, and allow extra workspace. Use the supplied rounded trig table when a task requests it. Legacy source previews remain separate from working generated tasks.

See MILESTONE3-VERIFICATION.md for tested scope and platform limits. GradeCam targeting remains Grade 5 only; cross-grade easier/harder suggestions are planned for Milestone 7.
