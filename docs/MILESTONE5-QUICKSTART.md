# Milestone 5 quickstart

Use **Test and Practice Studio v0.27.0-rc.2.html**. Open the downloaded file in a desktop browser. It is a self-contained local application with 1,910 working questions across six English banks.

1. Choose **Algebra 2** and enable the working-generator filter. There are 184 working entries, displayed 40 per page.
2. Search **M5** to find the 73 new family tasks. Examples: mixture / extract, gas / combined temperature, three / dependent, inequality / hole, proof / chord and statistics / population.
3. Preview and select tasks. Build a manual packet; choose student practice, answer key or study guide. Use a fixed seed/session to preserve the same question and answer variants.
4. Export to Word or print/save as PDF. Select A4 or Letter and one or two columns. Save a teacher session before leaving if you want to restore the selections and variants later.

Symbolic work, proofs, constructions and graph production require teacher review. Their keys include reference answers and criteria; the software does not automatically mark that work correct. Numerical questions state units, answer order and rounding. Population SD uses N, not N−1. Mixture extraction of pure solute differs from removing mixed solution. A zero vector has no direction.

Algebra 2 lesson-by-lesson completion is **Milestone 6**. These family tasks do not yet establish full course coverage. GradeCam standards targeting remains Grade 5 only; Algebra 2 works through manual selection without standards. Cross-grade easier/harder suggestions remain planned for Milestone 7.

Verified in desktop Chromium with actual Word/PDF export and rendered Word review. Native Windows Word, physical iPad and printer acceptance have not been performed. Earlier downloads remain available.
