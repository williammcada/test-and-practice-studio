# Use the completed foundational banks

Open `downloads/Test-and-Practice-Studio-v0.24.0-rc.2.html` in a current desktop browser. Choose Intermediate 4 or Course 1, and use the engine-only filter to show working generators. Search for a lesson or `M2 Lesson` to find the new authored tasks. Preview, select tasks, set variants and workspace, then export a student worksheet and a separate teacher key using Word or Print/PDF. Save the session to reuse the selection and seed.

Standards codes are not needed. Drawing, construction, survey and explanation tasks are marked for teacher review and have reference answers/rubrics in the key. Allow extra workspace or separate paper for physical constructions and nets; use a physical ruler for measurement. See MILESTONE2-VERIFICATION.md for tested scope and remaining platform checks.
