# Use the completed Algebra 1 bank

Open `downloads/Test-and-Practice-Studio-v0.26.0-rc.3.html` in a current desktop browser. Choose Algebra 1 and enable the engine-only filter. Search for a lesson or `M4 Lesson` to find the new authored tasks. The bank has 309 working entries across Lessons 1–120.

Preview and select tasks, set variants/workspace, and create a student packet with a separate teacher key using Word or Print/PDF. Save a teacher session for repeatable selections and seeds with this version. Earlier downloads remain available for earlier sessions.

Standards codes are not required. Symbolic methods, proofs, graphs and explanations use teacher review; keys give mathematical references and criteria. Supply graph paper and extra workspace for graphing and multi-step work. Calculator/graphing-software tasks explicitly say when those tools are needed. Keep the stated original domain restrictions and quartile/rounding conventions.

See MILESTONE4-VERIFICATION.md for tested scope and platform limits. GradeCam remains Grade 5 only. Cross-grade easier/harder suggestions remain planned for Milestone 7.
